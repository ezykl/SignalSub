## ✨ Features

- **🔔 Timely Alerts**: Proactive notifications before trial periods end and subscriptions renew.
- **📊 Spending Analytics**: Interactive donut charts, monthly & yearly projections, and category distribution.
- **📅 Renewal Calendar**: Visual timeline of all upcoming charges grouped by renewal date.
- **🔒 Local-First & Private**: Powered by local SQLite with instant offline availability and no account required.
- **🎨 Sleek Dark Interface**: Custom floating navbar with elevated quick-add action, smooth gradients, and OLED Midnight mode support.

---

## 🛠️ Tech Stack

- **Framework**: [Expo](https://expo.dev) + [Expo Router](https://docs.expo.dev/router/introduction/)
- **UI & Styling**: [NativeWind (Tailwind CSS)](https://www.nativewind.dev) + [Expo Linear Gradient](https://docs.expo.dev/versions/latest/sdk/linear-gradient/)
- **Database**: [Expo SQLite](https://docs.expo.dev/versions/latest/sdk/sqlite/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Charts & Icons**: [Victory Native](https://formidable.com/open-source/victory-native/) + Custom Vector Registry & Expo Vector Icons

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm start
```
Scan the QR code with the **Expo Go** app (Android/iOS) or press `a` for Android / `i` for iOS simulator.

### 3. Run Tests
```bash
npm test
```
